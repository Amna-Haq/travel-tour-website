# 🌍 Travel & Tour Website

A responsive **Travel and Tour Website** developed as a Web Technology course project. The website provides users with information about travel destinations, tour packages, and booking options through a simple and attractive interface.

## 📌 Project Overview

This project was created as part of a **Web Technology course** to demonstrate practical knowledge of front-end web development and basic PHP-based form handling.

The website allows users to:

* Explore travel destinations
* View available tour packages
* Learn more about the travel service
* View images and travel information
* Access a booking form
* Submit booking information

## ✨ Features

* 🏠 Home page with travel sliders
* 🌎 Travel and tour packages
* 📖 About Us page
* 📝 Tour booking page
* 🖼️ Travel destination images
* 🎨 Custom CSS styling
* ⚡ JavaScript functionality
* 📋 PHP-based booking form
* 📱 User-friendly website layout

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **JavaScript** – Client-side functionality
* **PHP** – Booking form processing
* **Images** – Travel destinations and website graphics

## 🚀 How to Run

### HTML/CSS/JavaScript

1. Download or clone this repository.
2. Open the project folder.
3. Open `home.html` in a web browser.

### PHP Files

The PHP booking functionality requires a PHP-enabled local server such as **XAMPP**.

1. Install XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Start **Apache** from the XAMPP Control Panel.
4. Open the project through your local server.
